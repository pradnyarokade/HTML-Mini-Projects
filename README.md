
# 💻 HTML Mini Projects

A collection of small web development projects created while learning and practicing HTML and web development.

## 📂 Projects

### 🪪 ID Card Generator
A simple project for creating an ID card using HTML.

### 💰 Interest Calculator
A basic calculator project for calculating interest.

### 📋 Marksheet Generator
A simple marksheet generation project using HTML.

### 🎵 Media Player
A basic media player webpage created using HTML.

### 🏦 Mini Bank
A mini banking project with basic banking-related operations.

### 🔤 Palindrome Checker
A simple project to check whether a given value is a palindrome.

### 📝 Question Paper Set
A webpage for creating and displaying a question paper set.

## 🛠️ Technologies Used

- HTML5
- CSS3

## 🎯 Purpose

These projects were created to practice HTML, webpage structure, forms, layouts, and basic web development concepts.
